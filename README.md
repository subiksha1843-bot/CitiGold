# Aurum Gold — Welcome Offers (front-end UI exercise)

A static HTML/CSS recreation of a premium wealth-management landing page, built as a
front-end coding exercise.

**Aurum Wealth / Aurum Gold is a fictional brand.** It is not a real financial institution,
and this page is not affiliated with any real bank. Every product, rate, offer and figure on
the page is invented sample content.

- No login, application, or form functionality — every link and button is inert (`href="#"`).
- No data is collected, stored, or transmitted. There is no backend.

## Running locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```
