# Citigold — Welcome Offers (front-end UI exercise)

A static HTML/CSS recreation of the Citigold welcome-offers page, built as a front-end
coding exercise.

**Not affiliated with, endorsed by, or connected to Citigroup Inc., Citibank N.A., or any
Citi brand.** All trademarks and brand assets belong to their respective owners.

- No login, application, or form functionality — every link and button is inert (`href="#"`).
- No data is collected, stored, or transmitted. There is no backend.

Do not enter real personal or banking information anywhere on this page.

## Running locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```
